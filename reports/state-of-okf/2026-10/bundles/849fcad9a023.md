## What to change

### Files with no frontmatter block (6)

OKF v0.2 §11 asks every `.md` file other than `index.md` and `log.md` to start with a YAML frontmatter block holding a non-empty `type`. The smallest change is:

```yaml
---
type: Note
---
```

If these files are not meant to be part of the bundle (a README, a changelog), moving the bundle into its own folder keeps them out.

- `AGENTS.md`
- `README.md`
- `assets/code-snippets/README.md`
- `assets/images/README.md`
- `quiz/answers.md`
- `quiz/questions.md`

### Files whose frontmatter does not parse (4)

The block between the `---` lines must be valid YAML that reads as a mapping. The parser's first message is shown for each file.

- `basics/variable-declaration.md: frontmatter is not valid YAML: mapping values are not allowed here`
- `getting-started/separation-of-concerns.md: frontmatter is not valid YAML: mapping values are not allowed here`
- `getting-started/setting-up-the-development-environment.md: frontmatter is not valid YAML: mapping values are not allowed here`
